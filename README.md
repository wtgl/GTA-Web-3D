# GTA-Web-3D
GTA Web 3D
GTA Web 3D
A 3D open-world browser game inspired by GTA, built entirely with HTML, CSS, and JavaScript. No plugins or downloads are required to play directly in your web browser.
Features
 * 3D Open World: City environment rendered using WebGL and a custom rendering setup.
 * Pedestrian and Vehicle System: Dynamic pedestrians walking around the city and drivable cars.
 * Police Chase: Wanted level mechanics and police cars responding to your actions.
 * Weapons and Combat: Functional weapon mechanics and action elements.
 * Movement System: Smooth character controls, sprinting, and environmental interaction.
Technologies Used
 * HTML5 / CSS3: Interface and base structure.
 * JavaScript (ES6+): Game logic, physics calculations, and input handling.
 * WebGL / Canvas API: 3D graphics rendering and scene management.
Getting Started
To run this project locally on your machine, follow these steps:
 * Clone the repository:
   git clone https://github.com/wtgl/gta-web-3d.git

 * Navigate to the project directory:
   cd gta-web-3d

 * Open index.html in any modern web browser (Chrome, Firefox, Edge). Alternatively, you can run it using a local server extension like Live Server.
Controls
 * W, A, S, D: Move / Drive vehicles
 * Shift: Sprint
 * F: Enter / Exit vehicles
 * Left Mouse Click: Shoot / Attack
 * R: Reload weapon
